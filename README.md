# Пугало против ворон

Маленькая браузерная игра: пугало (`Dummy.png`) защищает кукурузное поле от ворон.

Открой `index.html` в браузере — сборка не нужна.

- **← → / A D** или касание в нижней части экрана — ходить
- **Пробел** или касание в верхней части — крикнуть «БУ!» (распугивает всех ворон рядом, перезарядка 2 с)
- Вороны, которые подлетают вплотную к пугалу, улетают сами
- Золотые вороны — 25 очков, комбо от 3 ворон за один «БУ!» — бонус
- С каждой волной ворон больше и они быстрее; игра кончается, когда съедена вся кукуруза
