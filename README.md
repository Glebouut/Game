# Signal

Сцена главного меню игры на Unity (URP): дождливая ночь, бетонное здание «Varley»
с вышкой на крыше, ельник вокруг поляны, трава, грузовики и флаг, который треплет ветер.

## Откуда код

Скрипты в `Assets/Scripts/` восстановлены из релиза
[`fdafsd`](https://github.com/Glebouut/Game/releases/tag/fdafsd) —
из файла `Signal-Build-Base.zip` (Windows-сборка, Unity 6000.3.20f1, Mono).
`Signal_Data/Managed/Assembly-CSharp.dll` декомпилирован ILSpy.

Что важно знать про восстановленный код:

- **Имена локальных переменных потеряны** при компиляции — поэтому внутри методов
  встречаются `num`, `num2`, `vector3`. Имена классов, полей и методов настоящие.
- **Код только для редактора вырезан Unity из сборки.** В `VarleyBlockout` тела
  `Mat()` и `Tex()` были пустыми — они заново написаны под `#if UNITY_EDITOR`
  (ищут материал/текстуру по имени через `AssetDatabase`, иначе создают материал
  в `Assets/Materials`).
- Первый коммит с кодом — ровно то, что выдал декомпилятор; исправления лежат
  отдельным коммитом, их видно в `git diff`.

## Скрипты

| Скрипт | Что делает |
| --- | --- |
| `MenuCamera` | Камера меню «дышит» (шум Перлина) и слегка поворачивается за мышкой. |
| `BannerCloth` | Пункт контекстного меню **Make Cloth** превращает меш в ткань; при старте закрепляет край флага, ветер с порывами. |
| `BannerSound` | Шорох, хлопки и удары флага о стену — по скорости вершин ткани. |
| `GrassField` | 25 000 пучков травы через `Graphics.RenderMeshInstanced`, с пятнами и зонами-исключениями. |
| `TreeField` | ~450 процедурных елей (3 варианта меша) вокруг поляны, тоже инстансингом. |
| `VarleyBlockout` | Пункт **Build** собирает из кубов блокаут здания Varley: окна, крыльцо, свет, вышку. |
| `WetSurface` | Капли дождя, попавшие на поверхность, стекают к кромке и капают вниз. |
| `WaterFX` | Синглтон с системами частиц для струек и капель (его вызывает `WetSurface`). |

## Что исправлено

- `GrassField`: изменение `clumpWidth` / `clumpHeight` в инспекторе ни на что не
  влияло — меш пучка создавался один раз и больше не пересобирался.
- `GrassField`, `TreeField`: процедурные меши утекали в редакторе (`[ExecuteAlways]`
  создавал новые при каждом включении и никогда не удалял).
- `WetSurface`: пустой слот в массиве `corners` давал `NullReferenceException`
  каждый кадр; `flowSpeed = 0` давал деление на ноль.
- `VarleyBlockout`: с пустым `Mat()` пункт **Build** падал с `ArgumentNullException`
  (null-ключ в словаре `uvRules`).

## Про размер сборки

Архив весит 74 МБ, распакованный — 216 МБ. Самое крупное:

| Что | Размер |
| --- | --- |
| Текстуры (`sharedassets0.assets.resS`) | 84 МБ |
| `UnityPlayer.dll` | 37 МБ |
| `DirectML.dll` + `Unity.InferenceEngine*.dll` | ~15 МБ |
| Mono-рантайм | ~9 МБ |

Где можно сэкономить:

- **DirectML и Inference Engine** игре не нужны: ни один скрипт их не использует.
  Скорее всего, их притянул в проект пакет Unity AI. Если он не нужен в рантайме,
  удаление пакета уберёт ~15 МБ. Похоже, что лишние и Visual Scripting с
  Multiplayer Center.
- **Текстуры**: 12 штук 2048×2048 в BC7 по 5,6 МБ каждая (`*_set`, `*_mask`,
  `truck_northgate`, `military_utility`). Маски и мелкие предметы обычно не
  теряют в качестве при Max Size 1024 — это ~4 МБ экономии на каждой.
